# Suprland

Suprland is an experimental tiling window manager for Windows,
inspired by Hyprland.

It aims to bring:
- Dynamic tiling layouts
- Keyboard-driven workflows
- Smooth animations
- Event-driven window management

## Status
Early development. Expect bugs, missing features, and sharp edges.

## Goals
- Modern Win32-based WM
- No shell replacement (initially)
- Hyprland-like feel, Windows-native behavior

## Building
Currently built as a simple C++ application using Win32 APIs.

## Disclaimer
This is an experimental project. Use at your own risk.
